<h1>A projekt viziója</h1>
<h3>Eg olyan program létre hozása amivel létre lehet hozni az élő
szervezetek filogenetikus fa szerkezetét és számos meta adatot tárol adat tárolást. 
A program kezeli, módósítja az adat szerkezetet.</h3>

<h3>Ezzel az eszkökzel több ember összefogásával lehet lérehozni és szerkezteni a filogenetikus fát.</h3>
